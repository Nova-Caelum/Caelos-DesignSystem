# Match

Read `wireframe.json` and the catalog. Write `match.json` matching the schema, with one row for every need and no extra rows.

Use an entry name when an existing entry serves the need's purpose. Compare passive indicators and state indicators by purpose as carefully as controls. Use the nearest purpose-fit entry rather than inventing a new one.

Use `none` only when no existing entry serves the purpose. Use `none, new kind` only when the need requires a genuinely new structural or behavioral kind, and name that kind.
