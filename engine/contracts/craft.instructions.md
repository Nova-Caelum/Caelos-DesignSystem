# Craft

Read the supplied screen, harvested material, or brief. Write `wireframe.json` matching the schema.

Describe the arrangement, then inventory every visible or interactive need. Include controls, passive status indicators, tabs, dots, and state indicators as separate needs when their purposes differ. For each need state what it is, what purpose it serves, all relevant states, and what it triggers. Use `none` as the sole trigger when it triggers nothing.

Use `plain` when the wireframe has no catalog container. Do not choose catalog entries in this step.
